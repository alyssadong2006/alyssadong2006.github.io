PROJECT / 01NEUROEVOLUTION

Neuroevolution · Interactive simulation

Platformer Evolution Lab ↗

Build a level, then watch little neural-network agents learn to beat it. Each generation gets a new shot at figuring out when to run, turn, and jump.

TypeScriptReactViteNeural networksGenetic algorithms
Mission details +
  • Connected 13 sensor inputs to a 16-node hidden layer and three action outputs for left, right, and jump.
  • Preserved elite agents and generated new brains through crossover and mutation, using progress and goal completion to score attempts.
  • Simulated populations of 20–30 agents with fixed-step physics and generation-based training.

Neural Network Controller: Implemented a fixed-topology 13–16–3 multilayer perceptron with 275 weights and biases, using flattened genomes to compute dense affine layers with tanh activations for mapping observations to left, right, and jump scores.

Fitness-Based Neuroevolution: Evolved controller parameters across generations using 20% elitism, per-parameter uniform crossover, and Box–Muller Gaussian mutation (13% mutation probability; weights clamped to [−5, 5]); fitness rewards goal-distance progress, penalizes elapsed time, and adds a completion bonus.

Closed-Loop Agent Control: Built a real-time perception-to-action loop using 13 state features (eight directional distance sensors, goal offset, velocity, and grounded state); mapped network outputs to incremental horizontal steering and a grounded, threshold-triggered jump in a Matter.js physics simulation, without backpropagation.

PROJECT / 02WEB SECURITY

AI · Security · Developer tool

SafeParse ↗

A security gateway that checks web content before it reaches an AI system. It combines browser isolation, rule-based checks, and a trained classifier, then shows where it found a threat.

PythonFastAPIPlaywrightPyTorchHugging FaceDocker
Mission details +
  • Curated 9,280 examples and trained a DistilBERT classifier: 98.17% F1, 98.05% attack recall, and 2.01% false-positive rate on 1,517 test examples.
  • Added a validated batch API and JavaScript dashboard, with ordered results and isolated per-page errors.
  • Packaged offline CPU inference and validated 72 tests, including browser dashboard coverage.

Secure Web Ingestion: Built an asynchronous FastAPI/Playwright gateway with a shared Chromium process and isolated per-request contexts; inspected computed CSS visibility, applied NFKC normalization and zero-width character cleanup, and added a size-limited HTTPX fallback for HTTP/2 failures.

Dataset Curation: Curated 9,280 examples from four Hugging Face training datasets plus a separate source-held-out benchmark; pinned revisions and SHA-256 checksums, and built group-aware splits using document/pair/payload keys and minhash/Jaccard near-duplicate filtering to reduce leakage.

Custom Injection Classifier: Fine-tuned DistilBERT in PyTorch with document-level max-window binary cross-entropy over 512-token windows with 64-token overlap; used AdamW, gradient accumulation, and activation checkpointing, achieving 98.17% F1, 98.05% attack recall, and a 2.01% false-positive rate on 1,517 curated test examples.

Network Security: Hardened ingestion against SSRF by rejecting non-HTTP and credential-bearing URLs, checking DNS-resolved IP addresses against private, loopback, link-local, and reserved ranges, and revalidating redirects and every browser subresource request.

Batch API & Dashboard: Added a validated batch endpoint for up to 10 URLs with ordered results and per-page error isolation; extended the JavaScript dashboard with batch input, individual security reports, and JSON export while processing pages sequentially to bound browser resource use.

Defense-in-Depth & Delivery: Aggregated structural, regex, Unicode, and ML signals into a hybrid threat score; returned Pydantic audits with evidence offsets and randomized nonce enclosures, shipped offline CPU inference through safetensors and a checksum-verifiable release, and validated 72 tests, including batch API and Chromium dashboard coverage, with Docker and GitHub Actions support.

PROJECT / 03MACOS + WINDOWS

Desktop · Native apps

Waterloo Desktop Goose ↗

A goose that lives on your desktop. It wanders around, sits on your windows, and can be picked up and thrown. Native apps for macOS and Windows, with physics and hand-made pixel art.

SwiftAppKitC#WinFormsWin32
Mission details +
  • Implemented transparent, non-activating overlays with selective hit testing and window-aware navigation.
  • Built a 60 FPS simulation with gravity, collisions, Bézier flight paths, and independent character state machines.
  • Created pixel-art sprite tooling and packaged a universal macOS app and self-contained Windows builds.

Cross-Platform Native Architecture: Built native macOS and Windows desktop companions using Swift/AppKit and C#/WinForms; created borderless, non-activating transparent overlays with selective hit testing so animated objects remain draggable while the rest of the window passes input to underlying applications.

Window-Aware Navigation: Derived perchable ledges from live desktop geometry using CGWindowListCopyWindowInfo on macOS and Win32 window enumeration on Windows, subtracting occluded spans and continuously revalidating supports as users move, resize, or close windows.

Physics & State Machines: Implemented a 60 FPS simulation with gravity, velocity-based throwing, collision detection, spring-damper neck motion, and Bézier flight paths; coordinated independent state machines for the goose, fish, eggs, goslings, and coyote across walking, chasing, combat, hatching, and teleportation.

Rendering & Distribution: Generated runtime pixel-art sprites and animations from canonical character grids, wrote Python tooling to synchronize palettes across Swift and C#, and packaged a universal macOS application plus self-contained Windows x64/ARM64 executables.
