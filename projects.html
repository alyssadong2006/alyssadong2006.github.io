01SafeParseAI × WEB SAFETY
AI · Security · Developer toolFeatured

SafeParse — AI Web-Content Security Gateway

An asynchronous FastAPI and Playwright gateway that evaluates web content with structural, Unicode, heuristic, and machine-learning signals. It isolates browser requests, checks resolved addresses and redirects, and returns auditable reports with evidence offsets.

  • Curated 9,280 examples and trained a DistilBERT classifier: 98.17% F1, 98.05% attack recall, and 2.01% false-positive rate on 1,517 test examples.
  • Added a validated batch API and JavaScript dashboard, with ordered results and isolated per-page errors.
  • Packaged offline CPU inference and validated 72 tests, including browser dashboard coverage.

Moodii — Speech Emotion Diary

An Android audio diary that connects a Jetpack Compose client to authenticated Spring Boot and machine-learning services. Users can record entries, explore mood history, and receive emotion predictions from speech.

  • Connected the Android app to backend APIs with Kotlin coroutines, Retrofit, multipart audio, and JWT authentication.
  • Built a TensorFlow CNN–BiLSTM emotion classifier using Librosa MFCC features from four speech datasets.
  • Containerized the app build, backend, ML API, and MongoDB for Docker and Azure deployment.
