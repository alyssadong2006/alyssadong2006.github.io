# Alyssa Dong's Portfolio

An interactive, planet-themed research-report portfolio built with plain HTML, CSS, JavaScript, and Three.js. No build step or dependency installation is required.

## Run locally

ES modules need an HTTP server rather than opening the HTML directly:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://localhost:8765.

## Current design

- `index.html`: homepage with portrait, all seven projects, work experience, technical skills, education, hobbies and contact links. `hobbies.css` styles the off-duty stories and personal Moon photograph; the published image has location metadata removed.
- `projects.html`: standalone project archive with the same design and filters. The three projects covered by the resume include expanded technical notes; homepage internships have native expandable field notes.
- `resume.html` / `resume.css`: a separate personnel-record page containing the complete supplied two-page resume wording, with a section index, working contact links, responsive reading layout and a Print version link to the unchanged original `media/alyssa-dong-resume.pdf`. The PDF is not embedded into the on-screen page.
- `boot-screen.js` / `boot-screen.css`: a first-visit optical-sector scan (once per tab session/version). A full-screen coordinate grid, sensor sweep and target readouts discover AL-0527 and the MEOW constellation, then break apart into square pixels to reveal the site. The normal sequence targets 2.65 seconds with a 2.9-second visual failsafe, a Skip button and a static reduced-motion version. The Three.js modules preload and both scenes asynchronously compile shaders behind the scanner. Canvases are revealed only after a complete first render, with a fallback-to-canvas crossfade on slower devices rather than a blank flash.
- `sci-fi.css`: responsive observation-console design with larger typography, clearly labeled controls, text-first project cards, and the Polarizzzz / AL-0527 planetary report. Project cards contain only HTML text, tags, and links—no illustrations or image assets to update.
- `sci-fi.js`: project filtering, scroll reveals, scroll progress, pointer-lit card interactions, motion controls, and energy-pulse / meteor-shower controls.
- `planet-report.js`: a 1.8-second composition scan with calibration / spectral-analysis stages, a spectrometer display, sequentially revealed results, and a rescan button. Closing the report cancels the sequence. Pausing motion or hiding the tab finishes it immediately; reduced motion reveals results without animation. The native report also opens without JavaScript.
- `nebula-background.js` / `nebula-background.css`: cached original procedural rose/lavender clouds, layered stars, soft diffraction and slow drift across all pages, without another WebGL context. Motion stops when paused, reduced or hidden.
- `constellation-background.js` / `constellation-background.css`: a full-page 3D feline chart with smoothly shaded distant planets with four cached cloud/terrain/crater surfaces, rings and straight connections. Small white star clusters share the 3D rig and rotate with the planets. Eight baked color/height maps in `media/planet-surfaces/` reuse the browser image cache instead of regenerating noise on each page; the original generator remains an asset-failure fallback. Graphics initialization waits until an incoming pixel wipe finishes, and an offscreen homepage observatory starts only when approached. Its AL-0527 label follows the highlighted shoulder planet. A second lightweight renderer follows observatory pose changes and renders only while the view changes; the nebula remains if WebGL is unavailable.
- `version-switch.css`: a small native-link v1 / v2 / v3 switcher on every page. Its styling follows v1’s blue window UI, v2’s pixel beach or rounded pastel 3D theme, and v3’s pink sci-fi palette. V2 follows the original `daylight-theme` class without extra scripts or changes to its UI. The root site remains v3 (the current planet site), with no saved-version redirect. `versions/v1/` preserves the original site from `960e19a` (identical to the last original UI at `c0a049a`), and `versions/v2/` preserves the beach/pixel/3D site from `308f78b`, including its existing scenery switch. Historical CSS, scripts, media and vendor assets are copied unchanged; only the switcher markup and its stylesheet link are added to archived HTML. `versions/sources.json` records the snapshot commits. Switching retains the Projects page when available; v3-only pages fall back to an older version’s homepage. Native links support keyboard navigation, browser Back and no JavaScript.
- `ai-workflow.html` / `ai-workflow.css`: a separate, accessible long-form guide to Alyssa’s factory-guided AI engineering workflow. Covers context, scoped agent roles, local checks, behavior evidence, separate publication/ready approvals, bounded repairs, and limitations. Four HTML diagrams, including a simple five-step overview at the top, reflow on mobile and remain readable without JavaScript; an illustrative project-card UI change explains matched before/after captures, responsive layouts, interaction checks, and human verification without private work artifacts.
- `page-transitions.js` / `page-transitions.css`: lightweight pixel cover/reveal wipes for site navigation only. Planet / Star map retains the original smooth mode switch. Cross-page navigation uses a 90ms cover and immediate 180ms compositor-driven arrival reveal without waiting for DOMContentLoaded or graphics initialization. The arrival mosaic is rasterized once instead of repainting every frame, and background animation pauses while a wipe runs. Link hover/focus prefetches the next HTML document. Same-page jumps preserve history and focus; reduced motion / pause bypasses the extra transition.
- `space-effects.js`: sparse meteor showers, a fading comet trail for mouse pointers, and small click particle bursts on a topmost, click-through decorative canvas above cards and navigation. Objects are bounded, idle rendering stops, and effects are suspended in hidden tabs or when motion is off.
- `sci-fi-scene.js`: a stage-local Three.js observatory with a pearlescent planet, orbital particles, satellites, holographic measurement rings and a switchable cat constellation. Mouse dragging or keyboard arrows rotate the model and the background chart; plus/minus buttons or keys zoom. Reset view / Home restore orientation and zoom. The local star map highlights and labels AL-0527 at the same shoulder anchor as the background. Touch scrolling is not intercepted. The scene pauses outside the viewport. Scanning sends a pink latitude beam and coordinate grid across the planet.
- `cat-constellation.js`: an original seated-cat silhouette with upright ears, paws and a curled tail, sampled into prominent stars and straight constellation connections. A few internal body links and a very faint star field give it a celestial-map feel rather than a smooth logo. No image texture or external model is used.
- `core-explosion.js`: a reusable Three.js supernova with emissive fragments, thousands of glowing sparks, volumetric plumes and expanding shockwaves. Three core pulses temporarily move the transparent renderer into a full-screen, noninteractive portal so the blast escapes the observatory. Polarizzzz reforms after four seconds and the canvas returns to its pane. Pausing, hiding the tab or changing modes safely restores it.
- `impact-effects.js` / `impact-effects.css`: a rose energy wave and a gentle page-wide spring on each pulse; the explosion adds two wider shockwaves and a brief camera shake. There are no high-contrast white flashes; reduced motion disables the effects.
- `report-effects.css` / `report-effects.js`: luminous scientific frames for research, field operations, crew profile and communications. Brief pixel-dissolve entries, line draws and measurement diagrams are progressive enhancements; leaving a section never hides its content.

Three.js r160 is vendored in `vendor/three.module.js`; its MIT license is in `vendor/THREE-LICENSE.txt`. No external models, textures, or graphics CDN are required. Google Fonts supplies DM Sans, Space Grotesk, IBM Plex Mono, Orbitron and Rajdhani; system fonts are used when unavailable.

The scene caps pixel density and lowers geometry/particle counts on smaller or lower-core devices. It stops animating in hidden tabs, honors `prefers-reduced-motion`, and offers a footer motion toggle. A CSS orbital illustration provides a fallback when WebGL is unavailable. Portfolio content and native expandable project details remain readable without JavaScript; filtering and motion are progressive enhancements.

Existing beach-theme assets remain in the repository for experimentation but are no longer loaded by any page. Original dates, technical project details, project destinations, portrait, company logos and contact information were retained from the previous version. Employer logo sources are recorded in `media/company-logo-sources.md`. Introductions and project summaries use more conversational writing. Polarizzzz is a guiding light with a nap-powered recovery system. Its composition is a fictional metaphor, not a scientific or personality measurement.
